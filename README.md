# Hotel and Restaurant Furniture

A responsive furniture catalogue for the Vijayawada business, built with Next.js, React and TypeScript. The homepage uses the original nine photos; the dedicated gallery contains all 55 photos from the four category folders. Photos are served as compressed, responsive WebP copies. No prices are displayed.

## Live website

- Website: https://hotel-and-resturant-furniture.vercel.app/
- Gallery: https://hotel-and-resturant-furniture.vercel.app/gallery/
- Private source repository: https://github.com/SongsBeats/Hotel-and-Resturant-Furniture
- Vercel project: `hotel-and-resturant-furniture` in `songsbeats-projects`.

The production deployment was uploaded directly through the Vercel integration on 17 September 2026. The GitHub repository stores the source; automatic deployments from Git pushes have not been configured.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000. For a production preview:

```sh
npm run build
npm start
```

## Publish

1. Vercel builds automatically use `VERCEL_PROJECT_PRODUCTION_URL` for the site's public origin. To use a custom domain or another host, set `NEXT_PUBLIC_SITE_URL` to the actual HTTPS origin, with no path. The template is in `.env.example`.
2. Run `npm run build` and publish the **contents of `out/`** on any static website host, or configure a Next.js host to run the build.
3. Check the public canonical, social image, `robots.txt`, `sitemap.xml` and business JSON-LD. The sitemap includes the home and gallery pages. Local builds without either public URL variable are deliberately `noindex`.
4. Follow `SEO-LAUNCH.md` for the Google Business Profile and Search Console setup. Google Business Profile creation is a separate step after deployment.

## Content and interactions

- `lib/business.ts`: exact business name, phone, address, map coordinates, FAQ answers and structured data.
- `lib/collection.ts`: furniture titles, descriptions, categories and photo filenames.
- `lib/gallery-data.ts`: all 55 categorized gallery photos, titles, descriptions and reference IDs (generated by `scripts/prepare-gallery.mjs`).
- `app/gallery/page.tsx`: dedicated gallery, category filters, image metadata and shareable category links.
- `app/page.tsx`: server-rendered page content, including all city coverage and contact details.
- `app/globals.css`: design tokens and responsive styles, including system dark mode and reduced motion.
- The enquiry form opens WhatsApp with a prepared message; visitors send it themselves. No database or email service is required and the website does not save enquiry details.
- Product photos open in an accessible native dialog with keyboard navigation.
- Google Maps loads on request. Call and directions links work independently.

## Images

Original JPEGs remain in the project root. To regenerate the web assets:

```sh
npm run prepare:images
npm run prepare:gallery
```

This only resizes and encodes copies. Full photo framing is available in each product dialog. Thumbnail cropping is display-only CSS.

The production build generates the 480px and 800px responsive copies from the full-size WebP assets. Only one optimized web copy per photo needs to be uploaded or kept in version control; original JPEGs also remain available in the repository.

Gallery categories follow the supplied folders: Six Sittings (5 photos), Couple Sittings (6), Four Sittin Set (24), and Resturant Sofas (20). Original folders remain intact. To add new items, update the catalogue in `scripts/prepare-gallery.mjs`, then regenerate and rebuild.

